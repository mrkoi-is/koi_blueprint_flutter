# 架构治理

现行架构以 [架构契约](ARCHITECTURE.md)、[状态规范](state-management.md) 和受测样例为准。有效规范、Skill、生成器、样例与检查器同步维护。历史评分、其他产品迁移和旧命令结果由蓝图源仓维护，不继承到新项目。

依赖方向、纯 Dart domain、模块公共入口和同步 IO 是错误门禁。State 字段数与 Widget 回调数仅提示审查职责、生命周期和接口，不决定状态放置。ARCH012 已从通用门禁退役，编号不复用；媒体解析属于实际产品的行为测试。

新项目继承明确的指导资产清单；复制计划同时驱动来源基线。升级报告仅作三方比较，缺基线的指导文件标记 NO_BASELINE，人工核对，不补造旧基线。

验证包括受影响行为测试、完整 validate、全新生成工程及目标平台构建和运行。AI 冷启动与人类阅读反馈分别记录，资产存在或门禁通过不等同于可读性验收。
