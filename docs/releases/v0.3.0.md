# v0.3.0

本版本发布 Koi Flutter 蓝图源码，将 `v0.2.0`、`v0.3.0-android-rc.1` 和 `v0.3.0-rc.1` 的能力整合至 main。范围为 minimal / workbench 及默认 diagnostics v2；版本号属于蓝图源码，生成工程的应用版本与正式签名由项目自行配置。

## 主要变化

- 默认安装 diagnostics v2：Talker 日志及网络记录、设备内诊断页、分段持久化、导出与临时授权的局域网查看。Android release 构建支持前台诊断服务；使用与启停方式见 [诊断文档](../diagnostics.md)。
- 保留 SSE 初始订阅、活跃连接关闭、慢磁盘轮转和 Dio 流式正文结束时机修复。
- 英／简／繁使用统一 ARB locale policy，补齐 Apple 权限译文资源、Android 通知及渠道、LAN 标题与导出提示；保留 Windows 宿主生成 Apple 工程的 CRLF 兼容。
- 整合定向测试、Golden、持久化证据、受管升级事务、原生运行监督，以及会话异常清理与干净检出 CI 的依赖/生成修复。
- 同步 analyzer 14.5.0、build_runner 2.16.2；修正文档中默认诊断能力、完整能力选择及 Chrome 前置条件的过期描述。

## 迁移与验收边界

从历史 CI 基线 `v0.2.0-rc.1` 和 `5ec56a9` 直接跨入本版，会因 root/App/koi_core 依赖变化要求人工迁移。`Migration boundary` 验证预期冲突、拒绝应用及项目/来源记录不变，不表示自动升级或升级后运行通过。按 [升级指南](../upgrade-guide.md) 在隔离分支审阅，不伪造基线或删除冲突。

六端构建通过不等于六端完整国际化 UI 验收。系统语言变化、跨进程偏好冷启动、Apple 权限弹窗、人工视觉、完整 Web/Safari 和 Windows/Linux 国际化 UI 仍需验收；本轮没有重新完成 iOS 真机验收。macOS 托管 runner 的原生媒体图形烟测受图形能力限制，实际执行状态以归档中的能力记录为准。

历史 Android 真机局域网及 30 分钟锁屏验证、合并前 18 个语言检查分别保留原源码/安装包指纹，不能解释为最终发布安装包重复通过设备验收。详见 [Android RC](v0.3.0-android-rc.1.md) 与 [国际化记录](../localization-validation.md)。
