# v0.3.1

本补丁在 v0.3.0 基础上合入 `54716bd560c525c384119719e75fcc0108e6d1a8`，修复升级工具和诊断 LAN 的资源清理。v0.3.0 标签及其历史验证保持不变；v0.3.1 使用合并后的新 main 提交重新验证、构建并归档。

## 修复

- `upgrade plan` 保持受审工程只读：不生成 Python 缓存，计划必须输出到目标 workspace 和源蓝图之外。
- pub 解析前检查依赖 YAML 和本地路径：只接受可明确检查的块状依赖声明，拒绝别名、行内复杂映射、不明确的键和逃出隔离 workspace 的本地路径。
- 新增工具保留上游普通文件权限及执行位，已有文件保留本地权限；备份时和每次回退恢复前重新核对摘要，拒绝并发修改或损坏备份。
- LAN 停止期间保持 busy，重复停止共用清理任务，阻止清理中重新启动；取消订阅使用快照。Android 停服失败保留服务所有权，后续停止或宿主关闭可重试。
- macOS CI 使用自带 grep 查询媒体能力摘要，避免缺少 rg 时误报；同步初始化、工具和升级说明。

## 验证与产物

[GitHub Release](https://github.com/mrkoi-is/koi_blueprint_flutter/releases/tag/v0.3.1) 保存最终 main 提交、PR、完整门禁与 Quality CI、两模板六端构建、日志/测试证据和 SHA-256 索引。仅在所有适用门禁通过后发布；历史版本的结果不能代替本补丁的验证，不复用旧版本 APK。

生成应用为验收 fixture：Android APK 为 Release 编译、测试签名；iOS 未签名，桌面产物不表示分发签名或公证。蓝图源码版本与初始化应用版本分别管理。实际执行结果及未执行项以本版归档为准。

## 迁移与范围

受管升级仍只应用当前支持、无阻断的变更；任意依赖版本和可选能力包源码不会自动完整迁移。从 v0.3.0 引入本补丁的 `koi_diagnostics` 变更时，需审阅计划中的 `unsupported_managed_change`，在隔离分支人工迁移，不能只改 receipt 或基线摘要。历史依赖迁移矩阵只证明明确拒绝和无写入，具体步骤见 [升级指南](../upgrade-guide.md)。

本轮默认不重做历史 Android 真机 30 分钟锁屏验证；旧证据保留原源码和 APK 指纹。六端完整国际化 UI、系统语言变化、跨进程偏好冷启动、Apple 权限弹窗、人工视觉和 Safari 仍待验收；macOS 原生媒体图形烟测由 runner 能力决定，缺少图形能力时明确记为 NOT_RUN。目标平台构建、引擎行为与真实设备验收分别记录。
