# v0.3.0-android-rc.1

本候选包含 Talker 标准诊断能力，验收与分发范围为 Android RC。源码由同名 Git tag 固定；候选提交、CI 链接、日志、APK 和 SHA-256 由 GitHub 预发布的验收索引记录。本文件不将 CI 配置本身视为通过结果。

## 变更

- 新建 minimal/workbench 项目默认安装 diagnostics v2；显式 capabilities 列表保持精确选择。
- AppLogger、print/debugPrint、主 isolate 异常及已接入网络客户端进入宿主唯一存储；20 MiB 历史、脱敏、过滤、详情与 NDJSON 导出。
- release 在“关于”连续点击版本号七次进入，LAN 手动开启、随机凭证、实时更新，关闭后释放连接及 Android 保活资源。
- 网络流保持消费、错误、暂停/恢复和取消语义，诊断在正文实际结束后记录完成状态与耗时。
- 长日志在桌面双栏和窄屏正确换行。
- 生成器烟测按默认诊断的活动浏览器测试使用 Chrome；显式空 capabilities 另行验证不需要 Chrome；两种 Windows 模板均应用已固定的 SDK 浏览器 URL 兼容补丁。
- 突发日志按段大小写入，慢速磁盘上的批次合并不再产生整环大文件；SSE 在首帧发送前订阅变化，避免漏掉实时更新；LAN 回归覆盖活跃连接关闭，并增加 Windows 协议快速验证任务。

## 验收与归档

Android RC CI 对候选源码及两种全新 Android 工程执行完整 validate，另外构建两个测试签名 APK。源码完整门禁不降覆盖率阈值，既有 Quality workflow 继续运行。

[历史设备验收](../diagnostics-validation.md) 记录 Pixel 6a / Android 17 的日志、网络、持久化恢复、30 分钟锁屏、LAN 查询及设置还原。历史设备 APK 的来源摘要独立于本次 RC，归档索引必须分别标识，不能把它当成新候选再次真机执行的证据。CI 不接管用户手机，设备测试在 CI 中为 NOT_RUN。

发布归档包含候选源码提交、CI 结果、生成工程的来源清单、测试签名证书信息、日志及产物校验和；GitHub Actions 临时产物下载后另归档为本 RC 的 Release 附件。

## 范围

本候选不声明 iOS/macOS/Windows/Linux 实机认证，不承诺断电后的深度 Doze 或所有厂商系统保活。Web 可本地查看诊断，不能启动 TCP 服务端。既有升级工具、AI 测试工具等未提交工作不属于本次诊断发布改动。

## 正式签名待办

候选 APK 使用 Android Debug 测试证书，仅用于内部 RC 验收。正式签名需要维护者提供：

- 正式 applicationId；如更新已有应用，确认既有包名和签名/上传密钥。
- 本机 `.jks` / `.keystore` 文件路径和 key alias。
- store password、key password 通过本机安全环境变量或 CI Secrets 注入，不写进 Git、版本说明或聊天正文。

签名凭据就绪后另建正式签名 profile，重新构建、核对签名证书与升级安装；不把测试签名 APK 改名作为正式分发包。
