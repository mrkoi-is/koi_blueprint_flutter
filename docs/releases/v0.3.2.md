# v0.3.2

从 v0.3.1 升级时，将本地和构建环境切换到 Flutter 3.50.1 / Dart 3.14.0。新建 Android runner 使用 AGP 9.3.2，以修复 JDK 17 下的 release lint 崩溃。已有工程可在独立分支审阅 SDK 约束、锁文件和原生配置。[创建指南](../new-project.md)

## 工具变化

- Chrome 定向测试分别保存 JSON 用例事件和浏览器控制台日志，持久化测试据此核对实际执行的用例。
- `upgrade-report` 和 `upgrade plan` 共用 App 的 `pubspec.yaml` 包名。目录名与包名不同时，两条命令都能正确还原导入路径。
- 安装或刷新同版本能力时，ARB 逐个 key 合并。项目自定义文案会保留，配方新增 key 会补入，双方分别修改同一 key 时会报告冲突。
- 创建工程、`generate-check`、能力安装和完整验证共用 Pub 解析出的成员依赖顺序。安装在实际工程生成阶段失败时，会回滚安装清单，清理新包中可确认的生成产物，保留并发修改的源文件。

## 升级与验证

从已有 schema 2 工程调用新版蓝图的 `upgrade-report`，确认三方差异后再生成升级计划。项目对生成流程或本地化有自定义时，逐项合并对应入口和新工具文件。[升级指南](../upgrade-guide.md)

本版的源码提交、实际验证结果、平台构建和可下载资产以本次发布记录为准。生成应用的业务版本和签名由各自项目管理。[GitHub Release](https://github.com/mrkoi-is/koi_blueprint_flutter/releases/tag/v0.3.2)
