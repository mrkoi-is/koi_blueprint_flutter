# 初始化执行契约

输入为项目名、非冲突目标目录、组织标识和平台列表。先使用 dry-run 核对操作；实际创建遵循同一输入。目录冲突、非法名称、未知平台应在写入前失败。

输出包含独立 workspace、选定模板 App、koi_core/koi_ui、选定平台、工具链配置、AI 入口与测试。根 pubspec 决定成员；blueprint.json 只保存身份/平台/template。默认 minimal 不含认证、网络、文件、媒体和存储插件；workbench 的平台能力需独立验收。

验收：新目标能独立解析依赖，imports/平台标识使用新名称，AI 入口不存在指向作者目录的依赖，生成/格式/分析/测试/覆盖率通过，选定平台在对应主机完成构建。没有执行的阶段不得记为通过。

创建失败时保留诊断，不删除用户已有目录。是否清理由生成器明确标记的本次临时输出决定，不用 git clean/reset 处理。
